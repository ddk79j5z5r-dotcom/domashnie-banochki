# Домашние баночки

Приложение для iPhone (через ярлык на экране «Домой»): остатки бытовой химии и уходовых средств (шампуни, гели, кремы), прогноз «на сколько хватит», напоминания в Календаре и статистика трат.

**Открыть:** https://ddk79j5z5r-dotcom.github.io/domashnie-banochki/

## Как пользоваться

1. Откройте ссылку в Safari → «Поделиться» → «На экран „Домой“». Без ярлыка Safari может стереть данные, если не заходить 7 дней.
2. **＋** вверху справа — добавить средство. Средство — это назначение («Для посуды», «Шампунь»), а не бренд. Сразу укажите первую покупку: бренд, объём, единица, цена.
3. Время от времени **списывайте расход** — приложение покажет остаток. Быстрые кнопки подстраиваются под ваши обычные порции.
4. Купили новую упаковку — **«Купил новую»**. Приложение спросит, закончилась ли старая: «да» списывает её остаток, «нет» прибавляет к новой.
5. **🔔 Напомнить** — создаёт событие в Календаре за 5 дней до прогнозного конца, в 10:00.

## Как считается прогноз

- Пока не было ни одной докупки — по скорости списаний.
- После — по среднему сроку жизни прошлых упаковок (того же бренда, если есть). Если свежие списания показывают меньший остаток, прогноз опирается на них.

## Статистика

- Траты по месяцам и по категориям — по датам покупок.
- «Что выгоднее» — бренды внутри одного средства по рублям в месяц использования (цена упаковки ÷ сколько она прожила).

## Данные

Хранятся только в браузере телефона (localStorage), в репозиторий не попадают. Экспорт и импорт — на вкладке «Ещё» — для переноса на другой телефон.
